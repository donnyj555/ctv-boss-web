What still blocks us

  1. The same export for display

    The file we received is OTT_attribution_dashboard. Every row has zero clicks and a completion rate, so there is no display in it. Our display campaigns ran 9,806 impressions over the same period and are invisible here. We need the identical export for display — clicks and CTR matter there, completion rate does not.

  2. Publisher broken out by campaign

    Still outstanding. The publisher export is account-wide totals across 216 networks. “Your listing ran on Paramount, Hulu and Hallmark” is the line that renews a client, and we cannot say it truthfully for one agent. We need Campaign as a second dimension on that report.

  3. An ID on every row — this one is blocking real reporting

    The export carries Line Item Name and nothing else identifying. Line item names are not unique, so rows silently collapse: ten pairs of rows share a name and a date. On 12 August there are two separate rows both called Smart Way America Realty — Premium, at 381 and 190 impressions, belonging to different campaigns.

    The consequence is that 321 Inverness Dr cannot be reported at all. Its delivery sits inside line items named Smart Way America Realty — Premium and — Repeat CTV, and the Premium line item is shared with another campaign. There is no way to separate them.

    Adding Line Item ID, Campaign ID, Campaign Name and Advertiser ID fixes this completely.

What we're asking for

Priority 1

Add ID columns to Delivery Details

Without these, listings whose line items share a name cannot be separated, and we lose one listing entirely. This is a column addition to a report that already exists.

Line Item ID · Campaign ID · Campaign Name · Advertiser ID · Advertiser Name
Priority 2

The same Delivery Details export for display

Same columns, display inventory, with clicks and CTR populated. Completion rate is not meaningful there and can be dropped.

Priority 3

Publisher broken out by campaign

Same metrics as the current publisher report with one extra dimension, so each row is a campaign-and-publisher pair. A one-off export is fine to start.

Campaign ID · Campaign Name · Publisher · Impressions · Reach · Average Frequency
Priority 4

Schedule it daily

Previous day plus month-to-date, emailed as CSV each morning, so we can automate against it rather than pulling by hand.

Where this leaves us

The Delivery Details export was the breakthrough — completion rate and spend per line item per day is exactly the substance of an agent report, and 98.7% of our streaming ads playing to the end is the most persuasive number we have.

What remains is plumbing. An ID column tells us which listing a row belongs to. A display file covers the other half of the buy. Both are additions to reports that already run.
