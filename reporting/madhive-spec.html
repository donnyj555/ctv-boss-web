The four gaps

  1. Completes and VCR, per campaign

    Our account-wide VCR is 98.68% — the single most persuasive number we have. An unskippable ad that plays to the end is what an agent is buying. But it only exists on the topline export, so we can't attribute it to a listing. It needs to be a column on the campaign report.

  2. Spend, on impression-paced campaigns

    Spend appears only for budget-paced campaigns. All our listing campaigns are impression-paced, so Delivered Spend comes back empty. Without it there is no cost-per-view, no CPM, no efficiency story.

  3. Publisher broken out by campaign

    The publisher export is account-wide totals. "Your listing ran on Paramount, Hulu and Hallmark" is the line that sells a renewal, and we cannot say it truthfully for one agent. We need Campaign as a second dimension on that report.

  4. One key that joins the reports

    Campaign ID appears in the pacing and conversion exports but not in the campaign or publisher exports, which carry names only. We currently run four separate campaigns named Smart Way America Realty and nothing distinguishes them. Add Campaign ID — plus Advertiser ID — to every export.

What we're asking for

Priority 1

Add columns to the campaign report

This one change fills three of the four gaps and unblocks the agent report entirely.

Campaign ID · Advertiser ID · Advertiser Name · Impressions · Reach
Avg. Frequency · Completes · VCR · Delivered Spend · Impression Date
Total Conversions · Unique Conversions · Clicks · CTR
Priority 2

Add Campaign as a dimension on the publisher report

Same metrics, one extra dimension, so each row is a campaign-and-publisher pair rather than a publisher total. We understand this may need to be run server-side — a one-off export is fine to start.

Campaign ID · Campaign Name · Publisher · Impressions · Reach · Avg. Frequency
Priority 3

Schedule both as a daily CSV email

Previous day plus month-to-date, delivered each morning. This is what we need most until the API is ready — it turns a manual pull into something we can automate against.

Why this matters to us

Every agent who buys a campaign expects to see what their money did. Right now we can show them how many times their ad played and roughly how many households saw it — but not whether it played to the end, what it cost, or which networks carried it.

Those three answers are the difference between a report that renews a client and a report that raises questions. Everything else is already in your data; it just isn't in the export.
